SIH PS 34 — GIT TEAM INTEGRATION & WORKFLOW GUIDE
================================================================================

This guide explains step-by-step how to pull repository updates from your team 
members (Member 1 NestJS, Member 3 Flutter Mobile, Member 5 KB) and push your 
Next.js Web Frontend (Member 4) code to GitHub.

--------------------------------------------------------------------------------
STEP 1: CHECK YOUR CURRENT BRANCH & WORKING STATUS
--------------------------------------------------------------------------------
Open your terminal in the workspace root directory (c:\Users\shrav\OneDrive\Desktop\projects\SIH) and run:

    git status

This will show all your current changed, added, or modified files.

--------------------------------------------------------------------------------
STEP 2: PULL LATEST CODE FROM TEAMMATES
--------------------------------------------------------------------------------
Before pushing your changes, always pull the latest commits from the main repository branch so your local project has all backend (NestJS), mobile app (Flutter), and legal knowledge base updates:

    git pull origin main --rebase

If there are any merge conflicts, Git will mark them in the conflicting files.
To resolve conflicts, open the files, keep the correct code, and run:

    git add .
    git rebase --continue

--------------------------------------------------------------------------------
STEP 3: STAGE AND COMMIT YOUR WEB CODE
--------------------------------------------------------------------------------
Stage all your web application changes (including Next.js frontend, components, 
data/users.json, and configurations):

    git add .

Create a clear, descriptive commit message:

    git commit -m "feat(web): update Next.js frontend, map bounding, user registration persistence, and auth fixes"

--------------------------------------------------------------------------------
STEP 4: PUSH YOUR CODE TO GITHUB REPOSITORY
--------------------------------------------------------------------------------
Push your committed changes to the remote GitHub repository:

    git push origin main

If you are working on a dedicated feature branch (e.g. member-4-web), push using:

    git push origin member-4-web

--------------------------------------------------------------------------------
STEP 5: VERIFY YOUR DEPLOYMENT & TEAMS SYNC
--------------------------------------------------------------------------------
1. Check GitHub: Visit https://github.com/sumit21012006/Legal_Metrology to confirm 
   your commit and files are updated.
2. Run Web App: Test your local dev server:
       cd sih-web
       npm run dev
3. Test Integration: Verify that NestJS backend (Member 1) at http://localhost:3000/api/v1 
   communicates seamlessly with your Next.js web application.
